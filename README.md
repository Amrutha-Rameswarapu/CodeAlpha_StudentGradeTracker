# CodeAlpha Student Grade Tracker

## Project Description
Student Grade Tracker is a Java application that helps manage and analyze student grades. The program allows users to enter student names and grades, then calculates the average score, highest score, and lowest score.

## Features
- Enter multiple student names and grades
- Calculate average score
- Find highest score
- Find lowest score
- Display a complete student report

## Technologies Used
- Java
- Visual Studio Code (VS Code)

## How to Run

### Compile the Program
```bash
javac StudentGradeTracker.java
```

### Run the Program
```bash
java StudentGradeTracker
```

```
3
```
